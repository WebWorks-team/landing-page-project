# CRAFTLINE STUDIO — Premium Digital Creative Agency Website

> **"Crafting meaningful digital experiences through design and technology."**

A modern, responsive digital agency website built using HTML5, CSS3, and Vanilla JavaScript.

---

## 1. Project Overview

**Craftline Studio** is a digital creative agency website showcasing professional creative services, selected projects, client testimonials, and contact functionality.

This project is developed as part of an internship project, focusing on frontend development, responsive design, and interactive user experiences.

## 2. Technologies Used

- **HTML5** — Website structure and semantic markup.
- **CSS3** — Styling, animations, layouts, and responsive design.
- **Vanilla JavaScript (ES6+)** — Interactive functionality and dynamic elements.
- **Google Fonts** — Modern typography.

## 3. Key Features

- Modern and responsive design.
- Interactive navigation with mobile hamburger menu.
- Animated and centered hero section.
- About and services sections.
- Portfolio with interactive category filters.
- Interactive project details.
- Testimonials carousel.
- Contact form with client-side validation.
- Smooth scrolling and animations.
- Responsive layouts for mobile, tablet, and desktop.

## 5. How to Run Locally

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

No additional installation or build tools are required.

## 6. Project Note

Craftline Studio is a frontend web development project created as part of an internship project.

Portfolio projects and testimonials are sample content. The contact form includes client-side validation and does not connect to a backend server.
